# Research R3 — software stack, models, and train-vs-reuse decisions
Produce one table per component: thành phần | phần mềm / mô hình cụ thể (phiên bản) | giấy phép | chạy ở đâu (biên / cụm suy luận / cụm huấn luyện) | dùng nguyên hay tinh chỉnh (và trên dữ liệu gì, bao nhiêu mẫu) | lý do | phương án thay thế | nguồn.
Components:
1. OCR and document AI for Vietnamese construction paperwork (stamped acceptance records, handwritten site diaries, weigh tickets, BOQ tables): compare PaddleOCR-VL / PP-OCRv5 / PP-StructureV3, VietOCR, Surya, Docling, Marker, MinerU, dots.ocr, olmOCR, Qwen3-VL, InternVL/Vintern (Vietnamese). Which reads Vietnamese diacritics best, which handles tables, which is small enough. State clearly: which models are used as-is, which get LoRA fine-tuning on CC1 forms, how many labelled pages are typically needed.
2. Back end for OCR at scale: ingestion API, object storage, queue (e.g. Kafka/RabbitMQ/Redis + Celery/Temporal), GPU workers, human-review UI (e.g. Label Studio, CVAT, Argilla), schema/JSON validation, writing to PostgreSQL; throughput estimate pages/hour per GPU for the chosen models.
3. RAG assistant: embedding (bge-m3, Qwen3-Embedding, multilingual-e5), reranker (bge-reranker-v2-m3, Qwen3-Reranker), Vietnamese word segmentation for BM25 (underthesea, pyvi), vector store (pgvector, Qdrant, Milvus), search (OpenSearch/Elasticsearch), orchestration (LlamaIndex, Haystack, LangGraph), serving (vLLM, SGLang), chat front-ends usable via Zalo/mobile.
4. Ontology and knowledge graph: Neo4j vs Apache AGE vs others, LinkML for schema, IFC tooling (IfcOpenShell), LandXML, DWG/DXF reading (ezdxf, ODA File Converter), BOQ-to-norm-code mapping approach.
5. Agents: LangGraph / other agent frameworks, tool gateway, approval workflow, audit logging; MCP usage.
6. Training stack: Unsloth, LLaMA-Factory, TRL, verl / OpenRLHF for GRPO, Axolotl; data pipeline (dedup, PII removal for Vietnamese e.g. Presidio with Vietnamese recognisers), distillation.
7. Evaluation and ops: eval harness (lm-evaluation-harness, promptfoo, RAGAS, DeepEval), LLM observability (Langfuse, Arize Phoenix), MLflow, Prometheus/Grafana + NVIDIA DCGM; access control (Keycloak, OPA/Cerbos).
For the LLM itself, reuse the shortlist in research-261031-0917 (Qwen3.6 / Gemma 4 families) and only add what changed.
